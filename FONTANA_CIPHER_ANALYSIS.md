## Part 1: Fontana's Documented Cipher System

### Overview
Giovanni Fontana designed a **monoalphabetic substitution cipher** based on geometric primitives specifically optimized for:
- **Memorization** (not impenetrability)
- **Scribe readability** (easy for trained users to recognize)
- **Logical consistency** (systematic encoding rules)

### The Vowel System (Circle-Based)
Fontana's vowel encoding uses **concentric circles with directional tick marks**:

| Letter | Visual | Description |
|--------|--------|-------------|
| **A** | ⭕ + West tick | Plain circle with westward-facing mark |
| **E** | ⭕ + North tick | Plain circle with northward-facing mark |
| **I** | ⭕ | Unmodified circle ("squeezed" to suggest 'i') |
| **O** | ⭕ + South tick | Plain circle with southward-facing mark |
| **U** | ⭕ + East tick | Plain circle with eastward-facing mark |

**Compositional Logic**: The directional mark indicates the vowel. This creates the **cipher circle pattern** we identified in Voynich.

### The Consonant System (Geometric Patterns)

#### Set 1: Mirrored Forms (b, d, p, q, f)
- **b/d**: Horizontal flip of loop + stem
- **p/q**: Vertical flip of loop + stem
- **f**: Curved hooked form
- **Logic**: Mirror symmetry = easy visual recognition

#### Set 2: Counting System (h, k, m, n)
- **h**: Single vertical stem + single notch
- **k**: Vertical stem + two notches
- **m**: Vertical stem + three notches
- **n**: Vertical stem + two notches (variant)
- **Logic**: Stroke count = letter identity

#### Set 3: Structural Shapes (c, x, y, z)
- **c**: Open semicircle
- **x**: Clean crosshairs/cross
- **y**: Sharp angled lines (inverted hook)
- **z**: Angular zigzag
- **Logic**: Shape geometry = distinct visual identity

### The Speculum (Rotating Cipher Discs)
**Pages 23-38** of Fontana's *Secretum* document the **Speculum** - rotating discs with concentric circles:
- Inner circle: plaintext letters
- Outer circle: ciphertext letters
- Rotation mechanism: step through alphabet shifts
- Application: Creates polyalphabetic capability from base monoalphabetic system

**Key Feature**: The mathematical description of disc rotation and letter permutation.

## Part 5: Paleographic Evidence

### Fontana's Documented Hands

From surviving manuscripts of Giovanni Fontana (1421-c.1455):
- **BNF MS Latin 7296**: *Secretum de thesauro* (main manuscript)
- **BNF MS Latin 7297**: *Bellicorum instrumentorum liber*
- **Vatican MS Urb. lat. 1139**: Additional mechanical drawings

**Scribal characteristics**:
- Tight, economical script (saves parchment space)
- Consistent letter forms with slight geometric quality
- Frequent use of abbreviations (medieval standard)
- Dense layout with integrated drawings

### Voynich Scribal Hands (Davis 2020)

Davis identified **5 primary hands** in Voynich manuscript:
1. **Hand A** (main hand): ~85% of manuscript
2. **Hand B** (quires 20-22): botanical section variant
3. **Hand C** (codicological notes): later annotation
4. **Hand D** (sparse additions): isolated passages
5. **Hand E** (binding marginalia): edge additions
