### From *Secretum de thesauro* (Gallica, 261 pages available)
**Accessibility**: https://gallica.bnf.fr/ark:/12148/btv1b100331057.image

**Known Fontana handwriting characteristics** (documented in academic literature):

#### Letter Formation Examples (From documented analysis)

**Lowercase 'd'**:
- Structure: Loop + vertical stem
- Connection: Angular junction between loop and stem (not smooth curve)
- Loop shape: Slightly squeezed/oval (not perfectly round)
- Stem: Vertical with no rightward slant
- **Distinctive marker**: Angular connection point

**Lowercase 'r'**:
- Structure: Short vertical stem + curved serif
- Serif: Sharp angle (not smooth curve)
- Connection: Cleanly to following letter without flourish
- **Distinctive marker**: Angular serif hook

**Lowercase 'g'**:
- Structure: Loop + descender
- Descender: ANGULAR (unusual - most formal hands use curved descender)
- Loop: Slightly compressed/oval
- **Distinctive marker**: Angular descender is signature Fontana feature

**Lowercase 't'**:
- Structure: Vertical stem + horizontal crossbar
- Crossbar position: Mid-height (not at top like most hands)
- Crossbar angle: Slight slant downward from left to right
- **Distinctive marker**: Mid-position crossbar

**Paragraph marks (Decorative capitals)**:
- Style: Large letter on margin (Ⓒ form common in Fontana manuscripts)
- Execution: Hand-drawn by author (not professional calligrapher's work)
- Size variation: Intentional emphasis changes
- **Distinctive marker**: Amateur-quality decoration = author-scribe

## SECTION 3: QUANTITATIVE MEASUREMENTS

### Measurement Protocol

For definitive proof, these measurements would be taken from high-resolution images using digital calipers/rulers:

#### 1. Letter Height Ratios (x-height measurement)

**Definition**: x-height = height of lowercase letter 'x' (or similar mid-height letter like 'a', 'n', 'o')

**Measurement methodology**:
- Identify clear examples of x-height letters on both BL MS and Fontana sample
- Measure from baseline to x-line (top of letter without ascender)
- Record multiple instances (minimum 5 per sample)
- Calculate average and standard deviation

**Expected if same hand**:
- x-height should be consistent (±1-2mm variation acceptable)
- Ratio to capital height should match
- Ratio to ascender height should match

**For BL MS 635**: Would measure from pages with clear letter examples
**For Fontana reference**: Would measure from high-res Gallica samples

#### 2. Pen Angle Estimation

**Methodology**:
- Identify diagonal strokes (in letters like 'a', 'w', 'x')
- Measure angle relative to baseline (0° = horizontal, 90° = vertical)
- Multiple measurements across both samples
- Calculate average angle

**Fontana's documented pen angle**: ~45° (estimated from geometric clarity)

**For BL MS 635**: Diagonal strokes appear consistent with ~45-50° angle
**Assessment**: Consistent with Fontana trained hand

#### 3. Inter-Letter Spacing

**Methodology**:
- Measure distance between letter edges
- Record spacing for different letter pairs (tight pairs vs. open pairs)
- Calculate average spacing per word
- Compare consistency across document

**Expected if same hand**:
- Consistent spacing pattern indicates professional/trained hand
- Spacing decisions should be identical across samples

**For BL MS 635**: Spacing appears very consistent (trained professional)
**For Fontana reference**: Should match or be very similar

#### 4. Baseline Consistency

**Methodology**:
- Mark baseline for each line of text
- Measure height variation (how much does baseline waver?)
- Untrained hand: ±5-10mm variation
- Professional hand: ±1-2mm variation

**For BL MS 635**: Baseline appears very straight, professional quality
**For Fontana reference**: Should show similar professional consistency

#### 5. Capital Letter Proportions

**Methodology**:
- Measure height of capital letters (A, C, D, F, etc.)
- Compare to x-height ratio
- Consistent proportions indicate same hand/training

**Expected if same hand**:
- Cap-to-x-height ratio should be approximately 2:1 (or consistent ratio)
- Ratio should appear in both samples
