## INITIAL OBSERVATIONS (Pre-Analysis)

### Document Type
- Formatted list entries with decorated paragraph marks
- Mixed regular Latin text + cipher notation
- Catalog reference: R.D. 9318

### Key Features Observed
1. **Paragraph marks**: Distinctive large letters on left margin (consistent hand)
2. **Text mixture**: Regular Latin script alternating with encoded/cipher passages
3. **Ink consistency**: Single scribe across multiple pages
4. **Writing style**: Formal cursive Latin hand, 15th century period

### Critical Signature
- **Steganographic composition**: Regular text + cipher text on same page (Fontana trademark)
- **Cipher integration**: Not separate, but woven into document flow
