# The metal key and sevens

Pre-registration: `analyses/metal_key_prereg.md`. Key: flower colour → heraldic planet → metal. 10,000 shuffles within Currier language, seed 20261004; threshold p < 0.025 (Bonferroni over 2).

## Test 1: does the planetary scale order the text?

86 herbal pages. Pages per metal: silver (Moon) 19, copper (Venus) 6, gold (Sun) 1, iron (Mars) 10, tin (Jupiter) 50

- Spearman ρ (scale distance vs text similarity, different-metal pairs only): **-0.0793** (shuffled mean -0.0262); one-sided p = 0.207 → **NOT SUPPORTED**
