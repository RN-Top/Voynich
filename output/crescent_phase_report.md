# f67r2 crescents: waxing/waning runs?

Pre-registration: `analyses/crescent_phase_prereg.md`. Directions are recorded in the `crescent` column of
`analyses/moon_months_f67r2.csv`, from crops rotated so the ring centre is below each moon.

- **Result:** all 12 crescents (6 red, 6 gold) sit on the **anticlockwise** side of the face. M7 leans slightly
  toward the rim but is still anticlockwise.
- **Test:** with only one direction present, there are no changes to count, so the run test is not informative.
  The waxing/waning cycle is **NOT SUPPORTED**.
- **Reading:** the crescents follow one drawing convention around the ring. They do not show phases. The
  left/right difference seen in the close-up screenshots came from the screenshots being turned at different
  angles, not from the drawings.
