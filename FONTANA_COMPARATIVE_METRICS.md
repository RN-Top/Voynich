### Cipher System Documented Characteristics

#### Vowel Encoding (Circle-Based)
| Vowel | Visual System | Description |
|-------|--------------|-------------|
| **A** | Circle + West mark | Plain circle with westward tick |
| **E** | Circle + North mark | Plain circle with northward tick |
| **I** | Plain circle | Unmodified circle (squeezed to suggest 'i') |
| **O** | Circle + South mark | Plain circle with southward tick |
| **U** | Circle + East mark | Plain circle with eastward tick |

**Key Feature**: All vowels use CIRCLE base. Position of directional mark = vowel identity.

#### Consonant Encoding (Geometric Patterns)
| Category | Letters | Pattern | Visual Logic |
|----------|---------|---------|--------------|
| **Mirrored forms** | b, d, p, q, f | Loop + stem with horizontal/vertical flip | Mirror symmetry = easy recognition |
| **Counting system** | h, k, m, n | Stem + notches (count = letter) | Stroke count = identity |
| **Structural shapes** | c, x, y, z | Semicircle, cross, angle, zigzag | Shape geometry = distinct form |

**Key Feature**: Geometric consistency - each consonant has LOGICAL visual distinction.

#### Speculum (Rotating Cipher Wheels)
- Pages 23-38 of *Secretum* document rotating disc system
- Inner circle: plaintext letters
- Outer circle: ciphertext letters
- Creates polyalphabetic capability from base monoalphabetic system
- **Signature feature**: Mathematical precision + mechanical understanding

## PART 3: QUANTITATIVE COMPARISON FRAMEWORK

### Metrics That Can Be Measured

#### 1. Letter Height & Proportions
**Measurement needed**: 
- x-height (height of lowercase letter without ascender/descender)
- Cap height (height of capital letters)
- Ascender height (height of 'b', 'd', 'h', 'k', 'l')
- Descender depth (depth of 'g', 'y', 'p', 'q')

**Expected if same hand**: Consistent ratios across all text

#### 2. Pen Angle
**Measurement**: Angle of main strokes relative to baseline
- Estimate from diagonal stroke angles
- Consistent pen angle = same writing tool/technique

**Fontana's pen angle**: Estimated 45° based on geometric stroke clarity

#### 3. Spacing Patterns
**Measurements**:
- Inter-letter spacing (distance between letters)
- Inter-word spacing (distance between words)
- Line spacing (baseline to baseline)
- Margin consistency

**Single hand indicator**: Spacing patterns should be consistent throughout document

#### 4. Baseline Consistency
**Measurement**: How straight is the baseline?
- Professional hands: Consistent baseline ±1-2mm variation
- Unskilled writers: Baseline wanders significantly

**British Library observation**: Baseline appears very consistent = trained hand
